# L4 — Les paquets à la loupe

## OpenSSH Client

- Paquet : openssh-client
- Version installée : 10.2p1-2ubuntu3.8
- Origine : Ubuntu
- Fonction : permet de se connecter à distance à une machine avec SSH de manière sécurisée.

## Firefox

- Firefox est installé sous forme de paquet Snap.
- Version : 159.0.1-1
- Révision : 9171
- Éditeur : Mozilla
- Boutique : Snap Store.

## Sécurité des paquets

APT vérifie les signatures des dépôts et l'intégrité des paquets.
Si l'empreinte d'un paquet ne correspond pas aux informations
signées du dépôt, APT peut refuser son installation pour protéger
le système.

Télécharger un fichier .deb depuis un site inconnu est dangereux,
car il peut contenir un logiciel malveillant ou avoir été modifié.

## Conclusion

Firefox est installé depuis Snap Store.
OpenSSH Client provient des dépôts officiels Ubuntu.
Il est important de vérifier l'origine des logiciels avant
de les installer.
